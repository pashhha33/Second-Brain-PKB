## Открытые вопросы карты

1. Точные пути и границы предметных компонентов не утверждены (см. таблицу C): `ORCHESTRATOR_SYSTEM.md` указывает `docs/metamodel/`, `schema/`, `plugin/`, TASK.md — `metamodel/`, `schema/`, `plugin/` без префикса `docs/`. До решения (DL) о точных путях таблица C считается предполагаемой.
2. Правила `R-001`…`R-003` применяются, но не записаны в `RULES.md` — компонент A остаётся содержательно неполным.
3. Нет решения о технологическом стеке плагина — до его появления фаза 3 не может быть детализирована.

# TASK — итерация 002

## Цель
Создать начальную метамодель Second Brain PKB (v0.1) с шестью типами объектов (Заметка, Источник, Коллекция, Домен, Категория, Фасет), задать единую схему идентификации сущностей на основе ULID с префиксом типа, зафиксировать читаемое имя как обычное свойство. Формализовать базовые правила проекта в `RULES.md`. Завести два глоссария: по метамодели и по техническим терминам.

## Ключевые решения (зафиксировать в METAMODEL.md и DL-002)

1. **Типы объектов.** Каждая сущность — отдельный тип объекта. В v0.1 ровно шесть типов: Заметка, Источник, Коллекция, Домен, Категория, Фасет.
2. **Идентификатор сущности.** Формат: `<PREFIX>_<ULID>`, где `<PREFIX>` — 3–4-буквенный код типа из таблицы ниже, `<ULID>` — 26 символов Crockford base32 (48 бит времени + 80 бит случайности). ID неизменяем и не зависит от содержимого.
3. **Читаемое имя.** Хранится в свойстве `name` (или `title` для Заметки — выбрать одну конвенцию и применить ко всем типам одинаково). Не является идентификатором, может меняться, может дублироваться у разных сущностей (при необходимости уникальности — см. правила целостности).
4. **Префиксы типов:**

   | Тип | Префикс |
   |---|---|
   | Заметка | `NOTE_` |
   | Источник | `SRC_` |
   | Коллекция | `COL_` |
   | Домен | `DOM_` |
   | Категория | `CAT_` |
   | Фасет | `FAC_` |

   Префиксы фиксированы в v0.1; добавление новых — через новую запись в DL.

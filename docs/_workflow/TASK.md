## Что нужно сделать (Scope)
1. Создать файл `docs/CHECKPOINT.md` — зафиксировать текущее состояние: перечислить существующие файлы рабочего процесса, указать, что предметные артефакты отсутствуют, определить статус «Инициализация».
2. Создать файл `docs/project-map/PROJECT_MAP.md` — описать текущую фазу («Фаза 0: Каркас проекта»), перечислить известные компоненты (рабочий процесс, будущие метамодель, схема, плагин) и отметить, что они ещё не созданы.
3. Создать файл `docs/decisions/decision-log.md` — добавить первую запись `DL-001` с решением о создании базовых файлов состояния и обоснованием.
4. **Не создавать** пока файлы предметной области (`metamodel/`, `schema/`, `plugin/`) — только зафиксировать их в `PROJECT_MAP.md` как запланированные.
5. Все файлы оформить на русском языке, с чёткой структурой и ссылками на существующие артефакты рабочего процесса.
